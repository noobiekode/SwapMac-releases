# SwapMac releases

Downloads, the update feed and the website for [SwapMac](https://noobiekode.github.io/SwapMac-releases/),
a Mac app that shows what's filling your disk, explains each folder, and tells you what's safe to clear.

**Download:** [SwapMac.dmg](https://github.com/noobiekode/SwapMac-releases/raw/main/SwapMac.dmg)
(macOS 14 Sonoma or later, Apple silicon and Intel)

## What's here

- `SwapMac.dmg`: the newest version.
- `downloads/`: every version, and `appcast.xml`, the feed SwapMac checks for updates. Each
  update is signed, and SwapMac installs only updates with a valid signature.
- `docs/`: the website.

This repository only holds finished releases. Questions and feedback: content@triignite.com.
