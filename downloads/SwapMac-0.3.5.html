What's new in SwapMac 0.3.5

  • Cleanup History opens again: clicking it in the sidebar did nothing in recent versions. It also laid out off the screen when it had something to show. Both fixed.
  • No more off-screen windows: the fix behind that now covers every screen, so a note or a long line can never push the sidebar out of the window again.
  • License keys are checked more carefully: a key file copied from another Mac uses one of the key's three seats or is refused, and a key the server no longer recognises stops working right away. Nothing changes for keys bought and entered the normal way.
