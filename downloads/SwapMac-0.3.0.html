What's new in SwapMac 0.3.0

  • Developer: a new screen for the space developer tools fill. Build folders in old projects (node_modules, virtual environments, target, Pods), Xcode simulators and runtimes, Docker, local AI models from Ollama, Hugging Face and LM Studio, and package caches. Projects with uncommitted work are never ticked for you, and source files are never touched.
  • Each tool's own clean-up: simulators go through Xcode, Docker prunes itself, package managers clean their own caches. Anything that can't go to the Trash tells you so first, and what downloads again.
  • Any drive: More Scans lists your external drives by name.
  • Shared space: SwapMac tells you when a file shares its space with a copy, so moving it won't free as much.
  • Clearer map: tiles that need a look first or should be kept carry a mark, not just a colour.
  • VoiceOver reads the cleanup review, summary and History more clearly.
