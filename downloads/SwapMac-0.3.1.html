What's new in SwapMac 0.3.1

  • How SwapMac decided: the details panel and each row of the cleanup review now say why an item is marked the way it is. You see which rule matched, what it needs (such as the app being closed), whether the app it belongs to is still installed, and how safe it is to remove.
  • Intel Macs: the graphics memory note on the Dashboard now describes Intel's built-in graphics correctly, not only Apple silicon.
